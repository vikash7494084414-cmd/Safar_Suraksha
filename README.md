# SafarSuraksha – Expo Mobile App

A student hackathon MVP for return-first budget travel planning.

## Run on your laptop
1. Install Node.js LTS and VS Code.
2. Extract this ZIP.
3. Open the extracted `SafarSuraksha` folder in VS Code.
4. Open Terminal and run:

```bash
npm install
npx expo start
```

5. Install **Expo Go** on your Android phone and scan the QR code. Keep laptop and phone on the same Wi-Fi.

## Features in this MVP
- Budget planner with outbound, return, food, emergency and visit expenses
- Return journey verification switch (manual confirmation)
- Budget pass / exceeded status
- Sample budget destination list
- Google Maps search link
- Save / remove destinations

## Important limitations
- Destination costs are illustrative sample values, not live fares.
- Return verification is a user checkbox, not an automatic railway/bus check.
- No ticket booking, live transport API, user accounts, or cloud database yet.
- A passed budget calculation is not a guarantee of safety. Verify actual fares, service timings, local conditions and keep emergency funds separate.

## Hackathon pitch
"SafarSuraksha makes low-budget travel more responsible by planning the journey home first. If the return fare and emergency reserve do not fit, the app does not present the trip as ready."
